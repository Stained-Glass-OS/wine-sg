6060 appxpackaging (P-APPX: bundle writer, IAppxPackageWriter2/3). CreateBundleWriter was E_NOTIMPL; the package writer answered only IAppxPackageWriter. IIDs/layouts from the MIT windows-rs metadata (Win32::Storage::Packaging::Appx).
- writer.c: one writer object behind IAppxPackageWriter/2/3 (package) or IAppxBundleWriter/2/3/4 (bundle); QI keeps the two apart. Block hashes are kept per method (hash_methods[]): a package computes its settings' method, a bundle all three (SHA-256/384/512) since IAppxBundleWriter3::Close(hashMethodString) chooses at the end.
- Bundle: AddPayloadPackage reads the package with our package reader (block map checked), takes Name/Publisher/Version/Architecture/ResourceId, Properties ResourcePackage (=> Type="resource") and the Resources languages; all packages must share Name and Publisher (else APPX_E_INVALID_MANIFEST); names must end .appx/.msix and be unused (E_INVALIDARG). Packages are stored (method 0) and in the bundle block map; the manifest's Offset is the data offset (after the local header).
  Close: needs an application package (APPX_E_INVALID_MANIFEST otherwise); version 0 -> year.MMDD.HHMM.0 from UTC time (a choice: the docs say the version is generated from the time; the exact layout is ours). Manifest: http://schemas.microsoft.com/appx/2013/bundle, SchemaVersion 1.0, Identity, Packages/Package Type Version Architecture [ResourceId] FileName [Offset] Size, Resources/Resource Language. Content types: Default msix/appx application/vnd.ms-appx, bundlemanifest+xml, blockmap+xml.
  AddPackageReference (Writer3/4): listed with Size, no Offset, not stored (flat bundle). The bundle reader (package.c) now lets a Package with no Offset be absent from the archive.
  is_default_applicable_package (Writer4) is accepted and not recorded. AddExternalPackageReference (Writer2/4): E_NOTIMPL with a FIXME -- the OptionalBundle form is not written (left).
- Package writer: IAppxPackageWriter2::Close(manifest, contentGroupMap) checks the map is a well-formed ContentGroupMap document (APPX_E_INVALID_CONTENTGROUPMAP otherwise) and writes it as AppxMetadata\ContentGroupMap.xml (in the block map, content type application/xml). IAppxPackageWriter3::AddPayloadFiles checks the whole batch (names, types, options, repeats) before writing any; memoryLimit is advisory.
