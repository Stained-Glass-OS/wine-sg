3199 urlmon batch 2 (gap-A urlmon: 38 items implemented, 56 triaged one by one in g/dec/38). Implemented: Seek of file/mk/http/ftp/gopher/bind protocols (net protocols seek forward only), IStorage BindToStorage, progress statuses of custom protocols forwarded, URL moniker IsRunning/GetTimeOfLastChange/ParseDisplayName, HlinkSimpleNavigateToString via IHlinkFrame, CoGetClassObjectFromURL (installed class, or download through AsyncInstallDistributionUnit), FaultInIEFeature (installed class -> S_OK else S_FALSE), thread/zone feature controls + GET_FEATURE_FROM_REGISTRY, FixUnsecureSettings, IBinding::GetBindResult proxy/stub, URLOpenPullStreamW, callback wrapper Authenticate/GetBindInfo, SetSessionOption, foreign IUri errors passed on, CoInternetParseIUri escape actions, ftp/gopher on_error, INF hooks InfFile/InfSection, direct .ocx/.dll/.inf downloads. Side fixes found on the way: URLOpenStream/PullStream/BlockingStream used a stack callback that the bind kept using (now a heap object), UrlCombineW (kernelbase) lowercased the scheme of the caller's const relative URL in place (crash with literals), wininet InternetOpenUrl on FTP never sent REQUEST_COMPLETE when the connection failed (the bind hung).
Wine tests: tests/protocol.c and tests/url.c now skip the FTP checks when the connection fails (they used to hang and skip by timeout offline).
Gate test/fasturlmon-b2-gate.sh (111 checks, 64 and 32 bit): 27 mutants shown caught (FOREIGNERR PARSEIURI_ESCAPE URLMON_STORAGE _SETSIZE _STATUS _BPSEEK _SEEK _FILESEEK _ABORT(file,mk) _ISRUNNING _PARSENAME _NOFRAME _GETCLASS FIXSETTINGS _AUTH _BINDINFO _SESSOPT _THREADFEAT _REGFEAT _PULL _ONERROR _GETBINDRESULT _FAULTIN WININET_FTPFAIL _COMBINE).
GUESSES (not verified on Windows): HRESULT of failing Seek (E_FAIL), SetSize on the download stream (STG_E_ACCESSDENIED, by analogy with Write), IMoniker::ParseDisplayName eaten count (all characters), ftp/gopher request failures are reported as HRESULT_FROM_WIN32(wininet error) like Windows does for http name resolution (tests/url.c), INET_E_DOWNLOAD_FAILURE for other errors, FixUnsecureSettings deletes the user's HKCU policy values of zones 0-4 (the description says "reset to defaults"; the exact set is undocumented), IInternetSession::SetSessionOption forwards to UrlMkSetSessionOption (docs page has no description), HlinkSimpleNavigateToString failure of ShellExecute returns E_FAIL, thread-scoped features fall back to the process value when unset.
NOT covered by the gate: INF hook keys InfFile/InfSection and the direct .ocx/.dll/.inf install (they sit behind the install warning dialog), gopher on_error/Seek (same code as ftp, no server), the async download of CoGetClassObjectFromURL (no OnObjectAvailable after the install, documented as notification through the callback).
