5215 win32u: FlashWindowEx timers (gap-CORE 47).
Docs: learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-flashwinfo (FLASHW_CAPTION / TRAY / ALL, FLASHW_TIMER "flash continuously until the FLASHW_STOP flag is set", FLASHW_TIMERNOFG "until the window comes to the foreground", uCount "the number of times to flash the window", dwTimeout "the rate ... in milliseconds; if zero, the default caret blink rate").
NtUserFlashWindowEx only inverted the caption once (and told the shell once). When FLASHW_TIMER is set, or uCount > 1, it now also keeps a per-window record and a system timer of the window (SYSTEM_TIMER_FLASH_WINDOW, dispatched in NtUserDispatchMessage like the caret timer, so it needs the window's thread to pump messages): every dwTimeout ms (caret blink time when 0) it inverts the caption (WM_NCACTIVATE) and back; a flash is the inversion and its return; after uCount flashes (never for FLASHW_TIMER) it stops; FLASHW_TIMERNOFG also stops when the window is in front (caption restored to active); FLASHW_STOP, a new FlashWindowEx call, or the window's destruction ends the previous record. A timed flash that ends tells the shell's taskbar button to stop (HSHELL_REDRAW) as FLASHW_STOP already did. uCount 1 without FLASHW_TIMER stays the single inversion (FlashWindow(TRUE) toggles as before). The semi-stub FIXME is gone.
Unverified: whether native counts the first immediate inversion as the start of flash 1 (done here); that native stops a count-limited flash with the caption restored (done); the taskbar button's own flashing is the shell's (the HSHELL_FLASH code is sent once at the start as before); iconic windows run the timer without caption inversions.
