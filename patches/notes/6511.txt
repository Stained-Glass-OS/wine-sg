6511 avifil32 (ledger M-LEGACY: AVI clipboard). AVI files on the clipboard.
New clipboard.c: a read-only IAVIStream of one clipboard object (CF_DIB packed DIB -> one-frame video stream 'DIB ', 15 fps; CF_WAVE RIFF -> audio stream of its blocks), wrapped by CreateEditableStream (AVIMakeStreamFromClipboard; other formats AVIERR_UNSUPPORTED). AVIPutFileOnClipboard: an IDataObject (own IEnumFORMATETC) holding the IAVIFile, OleSetClipboard; GetData renders CF_DIB (AVIStreamGetFrame of the first video stream's start) and CF_WAVE (fmt + data of the first audio stream). AVIGetFromClipboard: this process's object while OleIsCurrentClipboard -> the file AddRef'd; else OleGetClipboard, CF_DIB/CF_WAVE streams -> AVIMakeFileFromStreams; none -> AVIERR_NODATA. AVIClearClipboard clears only this process's file.
