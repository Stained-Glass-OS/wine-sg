9200 dlls/ntdll/unix/server.c -- bugs1 (2026-11-22, sg-session's run-session-test hang): "wineserver -k" killed a just-started machine server before it answered a process's init_first_thread; the process blocked for ever in read() on its reply pipe and the session start with it.
Cause: init_thread_pipe() sends the reply pipe's write end to the server and the client kept its own copy until the reply came (close( reply_pipe ) after the request, in server_init_process and server_init_thread). With that copy open, a dead server never gives end-of-file on the read end.
Fix: the client closes its copy as soon as it is sent (the server's copy is in flight or received; the fd number is only the key the server files it under, per thread id, and nothing else is opened on that thread before the request). While the process is being started (first receive_fd to the init_first_thread reply), a closed connection is fatal_error "the wineserver exited before it finished starting this process", status 1 (was 0 or a hang); afterwards abort_thread(0) as before.
Gate srvdeath (test-srvdeath): stand-in server (test/srvdeath-standin.py) hands the process its connection via WINESERVERSOCKET, takes init_first_thread and dies, with the process's fds received (read) and left in the socket (noread). 1109: HUNG 20 s both. Fixed: ends in <1 s, status 1, message. Mutant SG_MUTANT_KEEP_REPLY_WRITER.
