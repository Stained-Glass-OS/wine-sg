6059 apphelp, sdbinst (P-SDB). apphelp's Sdb* database functions were stubs (SdbOpenDatabase etc. returned NULL) and sdbinst only printed a FIXME.
- dlls/apphelp/sdb.c (new): the .sdb format as documented publicly (12-byte header: major, minor, "sdbf"; WORD tags whose top nibble is the type; LIST/STRING/BINARY carry a DWORD size; even alignment; TAGID = file offset; STRINGREF = offset of a STRINGTABLE_ITEM from the start of the top-level STRINGTABLE's children).
  Reader: SdbOpenDatabase (DOS or NT \??\ path), SdbCloseDatabase, SdbGetFirstChild/NextChild (bounded by the parent list), SdbFindFirstTag/NextTag, SdbGetTagFromTagID, SdbGetTagDataSize, SdbRead{BYTE,WORD,DWORD,QWORD}Tag (wrong type -> default), SdbReadStringTag, SdbGetStringTagPtr, SdbReadBinaryTag, SdbGetBinaryTagData, SdbGetDatabaseVersion, SdbGetDatabaseID, SdbTagToString, SdbGUIDToString/FromString, SdbIsNullGUID.
  Writer: SdbCreateDatabase (version 2.1), SdbBeginWriteListTag/EndWriteListTag, SdbWrite{NULL,BYTE,WORD,DWORD,QWORD}Tag, SdbWriteStringTag (STRINGREF: one table item per distinct string; STRING: in place), SdbWriteStringRefTag, SdbWriteStringTagDirect, SdbWriteBinaryTag(FromFile), SdbCloseDatabaseWrite (appends the STRINGTABLE, writes the file).
  SdbInitDatabase/SdbReleaseDatabase: HID_DATABASE_FULLPATH opens the given file, HID_NO_DATABASE none, else %windir%\AppPatch\sysmain.sdb (we ship none, so NULL). No index writing (SdbDeclareIndex etc. stay stubs) and no matching (SdbGetMatchingExe): nothing applies shims; this is the file and install side only.
- programs/sdbinst: install copies to %windir%\AppPatch\Custom\{GUID}.sdb, writes AppCompatFlags\InstalledSDB\{GUID} (DatabaseDescription, DatabaseInstallTimeStamp, DatabasePath, DatabaseType 0x10000), AppCompatFlags\Custom\<exe> = "{GUID}.sdb" (QWORD time) per EXE NAME, an Uninstall\{GUID}.sdb entry; -u file / -g GUID / -n name remove it all; -q quiet; access denied is reported with exit 1.
Gate: test-sdbfile (probe writes/reads a database; sdbinst install and three uninstall forms).
