5100 netio.sys: WskSocket datagram sockets (finishes gap-CORE item 1067): WSK_PROVIDER_DATAGRAM_DISPATCH with WskBind, WskSendTo, WskReceiveFrom, WskRelease, WskGetLocalAddress, WskSendMessages.
WskSendTo: WSASendMsg (so control info works), overlapped; Flags must be 0 and ControlInfoLength needs a ControlInfo (STATUS_INVALID_PARAMETER); no RemoteAddress sends on a connected socket. WskReceiveFrom: WSARecvMsg overlapped; returns the sender in RemoteAddress, the control size in ControlLength and MSG_BCAST/MCAST/TRUNC/CTRUNC in ControlFlags; a datagram longer than the buffer completes with the buffer's bytes and MSG_TRUNC. WskSendMessages: each WSK_BUF_LIST entry is one datagram, sent by a worker; Information is the byte total. Chained MDLs go out as one datagram (gather list).
WskRelease returns STATUS_INVALID_PARAMETER: this subsystem never hands out datagram indication lists (no WskReceiveFromEvent), so a list passed back cannot be ours.
Docs: learn.microsoft.com/en-us/windows-hardware/drivers/ddi/wsk/nc-wsk-pfn_wsk_send_to, nc-wsk-pfn_wsk_receive_from, nc-wsk-pfn_wsk_send_messages, nc-wsk-pfn_wsk_socket.
