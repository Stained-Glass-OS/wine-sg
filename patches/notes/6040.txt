6040 wbemprox (COM-WMI "Left": CreateClassEnum). IWbemServices::CreateClassEnum/Async were FIXME stubs returning WBEM_E_FAILED, so SWbemServices.SubclassesOf (VBScript), System.Management GetSubclasses/Get-WmiObject -List and WMI browsers saw no classes.
What it does now:
- The class names are the namespace's tables (list_table_names, under the table list lock; spawned, unnamed and removed classes are skipped) plus the classes stored by applications (list_user_classes, HKLM\Software\Wine\WBEM\<ns>\Classes).
- Each class is given as a class object (create_class_only_object) over a query that is parsed but not run (exec_class_query). Filling every table would list CIM_DataFile, which is the whole disk; the first draft hung there.
- Filters: no superclass gives every class, or with WBEM_FLAG_SHALLOW only the classes without a superclass. A superclass gives its subclasses deep through get_class_parent, or with WBEM_FLAG_SHALLOW only the direct ones. An abstract class without a table (CIM_StorageExtent) is a valid superclass when it is some class's ancestor; any other unknown superclass is WBEM_E_INVALID_CLASS. Unknown flags are WBEM_E_INVALID_PARAMETER.
- The result is a new list enumerator (Next, Skip, Reset, Clone).
- CreateClassEnumAsync gives the sink the classes, then WBEM_STATUS_COMPLETE.
Gate wmienum (test-wmienum; 64- and 32-bit probes, two processes, VBScript SubclassesOf). It checks:
- all classes (more than 40, Win32_OperatingSystem, every one __GENUS 1), and shallow from the top (no superclass);
- CIM_LogicalDisk's subclasses (Win32_LogicalDisk, not itself), and CIM_StorageExtent deep (grandchild) vs shallow;
- an unknown superclass or flag;
- a stored class and a derived class enumerated in this and another process, and a deleted class gone;
- Async.
Mutants caught: SG_MUTANT_WMI_CLASSENUM_SHALLOW_ONLY (2 FAIL), SG_MUTANT_WMI_CLASSENUM_FILL (3: tables filled, the probes time out), SG_MUTANT_WMI_CLASSENUM_NO_STORED (10).
Conformance vs before (64/32): wbemprox query 0=0, wbemprox services 0=0, wbemdisp 0=0.
