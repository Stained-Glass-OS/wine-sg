6523 windows.media.mediacontrol (coordinator's row (a): the SMTC <-> MPRIS bridge, Wine half only; the shell side is main's). New unixlib windows.media.mediacontrol.so (unixlib.c/.h; UINT64-only params, the same funcs for wow64): libdbus dlopen'ed (SONAME_LIBDBUS_1), one private session-bus connection per enabled session, name org.mpris.MediaPlayer2.<exe name sanitized>.instance<unix pid>_<serial> (DO_NOT_QUEUE). Never autolaunches a bus: without DBUS_SESSION_BUS_ADDRESS only $XDG_RUNTIME_DIR/bus (a socket) is used. Serves /org/mpris/MediaPlayer2: Introspect, Properties Get/GetAll (Set refused: read-only), MediaPlayer2 (Identity = program name, CanQuit/CanRaise false) and Player (PlaybackStatus, LoopStatus, Shuffle, Rate, Volume, Position, Metadata: mpris:trackid, xesam:title/artist/album/albumArtist/trackNumber, mpris:length, mpris:artUrl as an escaped file:// URL; Can* flags); PropertiesChanged on every change. Player methods queue buttons only when enabled (Play=0 Pause=1 Stop=2 Next=6 Previous=7; PlayPause by status).
main.c: media_control_publish at every IsX/PlaybackStatus/AutoRepeatMode/Shuffle/PlaybackRate/timeline change and at DisplayUpdater.Update (which also reads the thumbnail: OpenReadAsync, ReadAsync into a Buffer; type from the content type or the bytes) ; unpublish at Release. A dispatcher thread (sg_smtc_mpris) waits on the bus (unix call, 250 ms) and raises ButtonPressed with a new SystemMediaTransportControlsButtonPressedEventArgs; it takes references only to controls not being released (CAS on ref, plus the weak ref as AddRef does).
windows.storage stream.c: reference_open_read on a foreign IRandomAccessStream without content type snapshots its bytes via GetInputStreamAt(0)+ReadAsync (5 s limit) instead of E_NOINTERFACE (picture_reference in metadata 6514 builds its cover over shcore's CreateRandomAccessStreamOverStream: its thumbnail could never be opened).
Gate mpris (test-mpris; dbus-run-session, gdbus, dbus-monitor, Xvfb): bus name, Identity, Metadata, artUrl file (JPEG, 0700 dir), PlaybackStatus, Can* flags, Set refused, PlayPause->Pause, Next, other thread, PropertiesChanged on Paused, PlayPause->Play, disabled Previous not raised, disabled session leaves the bus and removes its cover, no bus = no-op. Passes for 64- and 32-bit probes. Mutants SG_MUTANT_MPRIS_NO_SIGNAL (1 FAIL), SG_MUTANT_MPRIS_NO_BUTTON (5 FAIL), SG_MUTANT_REF_NO_FOREIGN (4 FAIL) caught.
