8231 t2embed G-EOT (ledger i0099 "MicroType Express (MTX) compressed EOT is refused"): dlls/t2embed/mtx.c implemented from the W3C Member Submission "MicroType Express (MTX) Font Format" (2008, public; the algorithm as the submission specifies it, own code -- its Appendix C sample code was read for the exact AHUFF tree initialisation, update order and LZCOMP preload, not copied). MTX header (version 3, block 2/3 offsets); LZCOMP per block: run-length bit, AHUFF trees dist(8)/len(8)/sym(256+8*ranges+3, ranges from the 24-bit output length), symbols: literal, DUP2/4/6, copy items (2-bit length groups with a continue bit, 3-bit distance groups, +1 length beyond distance 512), 7168-byte preload, the run-length layer (escape byte, count, byte). CTF: table directory as TrueType; glyf (numContours 0 empty, -1 composite with stored bbox, 0x7FFF stored bbox then contours, else bbox computed; 255USHORT contour point counts; 128-entry triplet table -- generated from the submission's table; pushCount/codeSize, push data 255SHORT with hop codes 251/252 re-emitted as PUSHB/PUSHW/NPUSHB/NPUSHW, then the code bytes); loca rebuilt long (head.indexToLocFormat = 1); cvt (delta coding, codes 238 word, 239-247 negative, 248-255 positive); hdmx (ppem/maxWidth pairs, then one LSB-first magnitude-coded surprise per glyph over the scaled hmtx advance; version >= 0x8000 = stored uncompressed as 0xffff-version); VDMX (group multipliers, ppem/yMax/yMin predictions + surprises, byte-aligned per group, ratio offsets remapped); checksums and head checkSumAdjustment recomputed. XOR (TTEMBED_XORENCRYPTDATA) undone before decompressing. Bounds-checked throughout (fuzzed 3000+150 corrupt inputs under ASan/UBSan, no faults; output capped).
Verified locally: DejaVu Sans (6253 glyphs, hinted) compressed by sfntly (Google, Apache-2.0) decompresses to the same tables and glyph outlines/components/programs. GUESS: a 0-contour glyph carries no pushCount/codeSize (as sfntly writes it; the submission's table is ambiguous).
