6519 winusb (ledger winusb i0231-i0238, plan step 1). The WinUSB API.
include/winusb.h: the API from its public documentation (policies, DEVICE_SPEED, WINUSB_SETUP_PACKET packed, WINUSB_PIPE_INFORMATION(_EX), all functions); USBD_PIPE_TYPE guarded (_USBD_PIPE_TYPE_DEFINED, also in ddk/usb.h) so winusb.h includes only ddk/usb100.h. include/wine/winusb_ioctl.h: private IOCTLs (all METHOD_BUFFERED: GET_INFO, GET_CONFIG, GET_DESCRIPTOR, CONTROL, READ_PIPE, WRITE_PIPE (data after the request), RESET_PIPE, ABORT_PIPE, SET_ALTERNATE) and the wineusb->winusb.sys internal GET_INTERFACE_GUID (used by 6520).
winusb.dll: handles = {magic, device (refcounted), interface number, alternate}; Initialize asks GET_INFO + GET_CONFIG (a handle that does not answer: the DeviceIoControl error, ERROR_INVALID_FUNCTION if none); GetAssociatedInterface (interface_count from the driver: 1 per wineusb PDO -> ERROR_NO_MORE_ITEMS); QueryInterfaceSettings/QueryPipe(Ex)/ParseConfigurationDescriptor/ParseDescriptors from the cached configuration; QueryDeviceInformation(DEVICE_SPEED); GetDescriptor; Control/Read/WritePipe: the program's OVERLAPPED passed through, or an own one waited for with the pipe's PIPE_TRANSFER_TIMEOUT (CancelIoEx -> ERROR_SEM_TIMEOUT); Reset/AbortPipe; FlushPipe (nothing buffered); Set/GetCurrentAlternateSetting; Set/GetPipePolicy (all documented policies, MAXIMUM_TRANSFER_SIZE read-only 4 MB); Set/GetPowerPolicy (AUTO_SUSPEND, SUSPEND_DELAY kept); bad handles ERROR_INVALID_HANDLE (magic checked under an exception handler).
Gate winusbapi (test-winusbapi, host): parsers on a configuration of the probe's own, bad-handle and not-a-device errors, the driver and INF installed (the latter from 6520). Mutant SG_MUTANT_WINUSB_PARSE_UNBOUNDED caught. The device path is test-winusb (6520), on a VM with test/usbgadget-setup.sh.
