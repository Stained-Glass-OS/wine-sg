RpcAsyncGetCallStatus (item 556) used to return RPC_S_INVALID_ASYNC_HANDLE
unconditionally. Now:
 - NULL handle: RPC_S_INVALID_ASYNC_HANDLE.
 - handle that never started a call (no StubInfo): RPC_S_INVALID_BINDING,
   as the Windows-verified tests in tests/rpc_async.c expect (todo_wine removed).
 - client async NDR call: RPC_S_ASYNC_CALL_PENDING from call start until the
   reply is received, then RPC_S_OK (RPC_S_CALL_FAILED if the connection fails).
The status lives in struct async_call_data and is set by the async notifier.
Limitation: Wine's server dispatch is synchronous, so server-side async
completion/abort/cancel is not supported (see escalate-6.md for 557/558/587).
Gate: test/rpcrt4-async-gate.sh (widl-generated async stubs, 64+32 bit);
mutants: always-INVALID_ASYNC_HANDLE and no-notifier-update both fail it.
