3717 windows.security.enterprisedata (gap-CLOUD): every IProtectionPolicyManagerStatics* "Async" method used to answer E_NOTIMPL (no_async). Now they return IAsyncOperation objects that are completed at once (async.c, one macro for three result types): RequestAccess{,ForApp}Async, RequestAccess{WithAuditingInfo,WithMessage,ForAppWithAuditingInfo,ForAppWithMessage,WithBehavior,ForAppWithBehavior}Async and RequestAccessToFilesFor{App,Process}{,WithMessageAndBehavior}Async and IProtectionPolicyManagerInterop::RequestAccessForWindowAsync give ProtectionPolicyEvaluationResult_Allowed (the same answer CheckAccess gave since 1526), IsFileProtectionRequiredAsync/ForNewFileAsync give false, GetPrimaryManagedIdentityForNetworkEndpointAsync an empty string. edp.idl now spells the real result types (windows-rs 0.58.0, crates/libs/windows/src/Windows/Security/EnterpriseData/mod.rs, gave the signatures: IAsyncOperation<ProtectionPolicyEvaluationResult> for all RequestAccess*, IAsyncOperation<bool> for the two IsFileProtection*, IAsyncOperation<HSTRING>); the three IAsyncOperation iids and handler iids were recomputed with the WinRT pinterface SHA-1 rule and match widl's. IAsyncInfo/handler behaviour (Completed at once, handler runs inside put_Completed, a second handler is E_ILLEGAL_DELEGATE_ASSIGNMENT, Close makes later calls E_ILLEGAL_METHOD_CALL, Cancel on a finished operation is S_OK) follows Wine's own tests of other WinRT async classes that were run on Windows. GetIids/GetRuntimeClassName/GetTrustLevel for the manager (IProtectionPolicyManager + 2), the thread network context (default interface + IClosable), the factory (statics 1-4, interop, IActivationFactory: the factory list is a GUESS). DllGetClassObject clears *out. Unknown-IID E_NOINTERFACE and ActivateInstance E_NOTIMPL (static class) are right as they were.
NOT done: requests never block or ask for consent (consent/blocked results only matter with a policy, and none can exist here).
Gate fastb-edp (one probe, 16 request kinds). Mutants caught: EDP_BLOCKED, EDP_FILEPROT, EDP_GCO, EDP_GETIIDS, EDP_NOINVOKE, EDP_NOCLOSE. The older gate edppolicy still passes (64 and 32).
