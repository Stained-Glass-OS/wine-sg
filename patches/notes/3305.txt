3305 winex11 synthetic ConfigureNotify/GravityNotify in a virtual desktop (CORE review). Verified through the driver's own trace (warn+x11drv "unexpected config") for ConfigureNotify with the desktop window moved on the root by the test client; GravityNotify (embedded windows only) uses the same helper and was NOT exercised. The Win32 window itself does not move in the test: in a virtual desktop the window is not synced from configure events here (window_update_client_config requires the managed flag set by the WM state); this patch does not change that. No window manager was available: the event is sent with XSendEvent by the test client, as ICCCM describes a WM would.
winex11 has no Wine test unit. Behaviour change: only synthetic (send_event) events in a virtual desktop; real events and the non-virtual-desktop case are unchanged.
