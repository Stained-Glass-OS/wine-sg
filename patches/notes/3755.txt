CORE review: user32 + win32u cursors (every program loads system cursors through CURSORICON_Load; win32u NtUserSetCursorIconData gets a private replace flag). Docs: learn.microsoft.com SetSystemCursor ("replaces the contents of the system cursor specified by id with the contents of the cursor specified by hcur and then destroys hcur"; ids OCR_APPSTARTING NORMAL CROSS HAND HELP IBEAM NO SIZEALL SIZENESW SIZENS SIZENWSE SIZEWE UP WAIT), SystemParametersInfo SPI_SETCURSORS ("reloads the system cursors").
Design: the replacement is stored for the session in the volatile HKCU\Software\Wine\Temporary System Parameters\System Cursors, value "<id>" = the cursor as a cursor resource (hotspot + DIB: 32-bpp XOR + AND for colour/alpha cursors, 1-bpp AND over XOR for monochrome ones; built from GetIconInfo/GetDIBits). SetSystemCursor changes the process's shared system cursor handle in place (NtUserSetCursorIconData with flag 0x40000000 replaces the frame of an initialized static cursor, deletes the old bitmaps and drops the X11 driver's copy), writes the store, destroys hcur. CURSORICON_Load applies the stored replacement to every system cursor it newly creates (shared or not), so processes started later get it. SPI_SETCURSORS (intercepted in user32 SystemParametersInfoW) deletes the store and reloads the default image into every replaced handle of the process.
Limits / GUESSES: (1) processes that are already running keep the cursors they loaded (cursor handles are per-process in Wine; no change broadcast). (2) Animated hcur: only its first frame is kept. (3) Error codes: unknown id -> ERROR_INVALID_PARAMETER, icon or bad handle -> ERROR_INVALID_CURSOR_HANDLE are guesses. (4) The X cursor refreshes on the next WM_SETCURSOR (mouse move), not at once. (5) Cursors loaded at another size than the replacement are used as stored (no stretch). No new syscall or server request: win32u.so + user32.dll only.
Gate fastb-syscur (mono and alpha colour replacement, same handle, untouched others, non-shared load, child process, errors incl. refused cursor not destroyed, SPI_SETCURSORS, child after restore); 12 mutants caught (NOT_IN_PLACE NOT_STORED NOT_DESTROYED BADID_ACCEPTED ICON_ACCEPTED LOAD_NOT_APPLIED RESET_KEY_KEPT RESET_NO_RESTORE HOTSPOT_LOST SPI_IGNORED W32U_NO_SWAP COLOR_AS_MONO). Conformance 64/32 vs the series-applied base (3754 applied): user32 and win32u identical.
