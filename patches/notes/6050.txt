6050 dcomp (G-WINRTCOMP, second slice: the expression evaluator). After 6048 expression animations were kept, not run, and expression key frames understood only this.StartingValue/CurrentValue/FinalValue and plain numbers.
New expression.c: recursive-descent parser into a tree (expr_parse), evaluator (expr_eval) over values of kind scalar, boolean, vector2/3/4, quaternion, colour (A,R,G,B 0-255).
- Grammar, loosest to tightest: ?: ; && || ; < <= > >= == != ; + - ; * / % ; unary - ! + ; numbers (an "f" suffix allowed), true/false, (..), names, calls.
- Names (case-insensitive): parameters (scalar/vector/colour/quaternion values, ".X"/".XY"/".A".. components); reference parameters' properties ("src.Offset.X", "props.Foo"), found once through the object's own StartAnimation with an internal probe animation (struct animation.probe), so every object's resolver (visual/brush/clip/property set tables, the object's Properties set) answers; this.StartingValue and this.FinalValue (the value at start: no implicit animations), this.CurrentValue, this.Target.Property.
- Arithmetic component-wise between like kinds, scalar broadcast against vectors; comparisons on scalars; == and != on any.
- Functions: Abs Acos Asin Atan Ceil Cos Floor Ln Log10 Round Sin Sqrt Square Tan ToDegrees ToRadians (component-wise), Vector2/3/4 and Quaternion (from scalars and smaller vectors), ColorRgb/ColorArgb(a,r,g,b), Min Max Clamp Lerp ColorLerp ColorLerpRgb Mod Pow Scale Length LengthSquared Distance DistanceSquared Normalize Slerp CreateFromAxisAngle. Others: FIXME, the expression gives no value. Matrices are not supported.
animation.c:
- StartAnimation with an expression animation: the target must exist (E_INVALIDARG otherwise, as for an empty expression); parameters are copied at start; it is evaluated at once and at every step (15 ms timer) until StopAnimation or a new animation on the property; a value of another kind than the property is skipped; the property is written (and a commit asked for) only when the value changed. Not in batches; StopAnimation leaves the current value.
- Expression key frames: parsed when inserted (malformed: E_INVALIDARG), evaluated when the animation starts with the key frame animation's parameters and this.StartingValue; if not evaluable, the key frame holds the previous value (FIXME).
