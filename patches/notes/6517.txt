6517 wmvcore (ledger M-DSHOW: WMWriter_BeginWriting, steps 1-2 of the plan agreed with main). The writer writes ASF files.
asfmux.c (from the public ASF specification only): at BeginWriting, the profile's streams (number, bitrate, buffer window -> preroll = the largest; media type -> type-specific data: WAVEFORMATEX with cbSize, or encoded width/height + reserved 0x02 + format data size + BITMAPINFOHEADER; other stream types NS_E_INVALID_STREAM). Header: File Properties (file id from CoCreateGuid, creation time, broadcast flag until the end, then seekable), Stream Properties (no error correction), empty Header Extension (reserved GUID, 6, 0), CDO/ECD of the writer's attributes (shared asf_put_descriptions, moved from the editor into asf.h helpers). Data object: 3200-byte packets, error correction 0x82 0 0, length type 0x10 (one payload, WORD padding), property flags 0x5d, send time = presentation ms, payload: stream (0x80 clean point), media object number, offset, replicated data (object size, presentation ms + preroll); media objects split over packets. Simple Index per video stream (1 s interval, last clean point at or before each second). EndWriting: index written, header rewritten in place with packet count, play/send durations, file size (it keeps its size), data object size/count; sinks: OnHeader(header + data object header), AllocateDataUnit/OnDataUnit per packet, OnEndWriting.
writer.c: BeginWriting creates/begins the mux (a second Begin while writing NS_E_INVALID_REQUEST); WriteSample: input whose chosen format is the stream's own (PCM -> PCM, RGB/YUV video stream fed the same) goes in with its duration (bytes / avg bytes per second, or AvgTimePerFrame); other formats need an encoder: E_NOTIMPL with a FIXME (plan step 3: wg_transform encoders); WriteStreamSample: stream samples as given; Flush S_OK while writing; EndWriting ends the file; GetStatistics fills sample and byte counts. Not done: the Header Extension's extended stream properties, codec list, script streams, multiple payloads per packet.
