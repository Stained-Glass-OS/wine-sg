Implements: server-side async (process_request_packet keeps the call, I_RpcAsyncSetHandle on a server binding, I_RpcSend as the response, NdrpCompleteAsyncServerCall / NdrpFreeAsyncServerCall, RpcAsyncAbortCall/I_RpcAsyncAbortCall fault, exception of the manager ends the call with a fault), client RpcAsyncCancelCall (abort: CancelIo/cancel_event + notification; no abort: PKT_CO_CANCEL), RpcServerTestCancel, NdrServerCallAll, pending check in RpcAsyncCompleteCall, notifier with a state copy (also failure and cancel), TCP wait_for_incoming_data peeks, header-only packets do not read.

Not done (escalated): NdrAsyncStubCall and NdrDcomAsync* (DCOM async needs the ICallFactory/CStdAsync machinery of ole32), Ndr64AsyncClientCall (NDR64 transfer syntax absent), asynchronous calls with pipes, async calls with the server interface unregistered meanwhile.
