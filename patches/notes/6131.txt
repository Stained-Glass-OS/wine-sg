6131 windows.ui.xaml main.c -- regression guard for 6129 (main's request, 2026-10-26).
Risk: 6129 registered Windows.UI.Xaml.Application, .Window, .Hosting.WindowsXamlManager and .Hosting.DesktopWindowXamlSource. Before, RoGetActivationFactory for any Windows.UI.Xaml class failed with REGDB_E_CLASSNOTREG (combase: no registration). A program that probes for XAML and falls back to Win32 on failure would now take the XAML path into a XAML that draws nothing.
Now DllGetActivationFactory returns REGDB_E_CLASSNOTREG (the same result as before) for every class unless XAML is on for the program: HKCU then HKLM Software\Wine\AppDefaults\<exe name> SgXaml REG_DWORD != 0; or Software\Wine SgXaml (all programs); or environment WINE_SG_XAML=1 (gates, development). Decided once per process.
Classes by step: 6129: Application, Window, Hosting.WindowsXamlManager, Hosting.DesktopWindowXamlSource. Next (6132): DependencyObject, DependencyProperty, PropertyMetadata. All behind the switch until the milestone where XAML draws (step 4), when the default can be revisited per class.
