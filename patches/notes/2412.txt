2412 wtsapi32: WTSLogoffSession, WTSDisconnectSession, WTSSendMessageA/W, WTSShutdownSystem act (coordinator decision 4).
Own session (WTS_CURRENT_SESSION / own id): no rights. Other: administrator (CheckTokenMembership, thread token) else ERROR_ACCESS_DENIED; for an administrator session 0 -> ERROR_ACCESS_DENIED, unknown -> ERROR_NOT_FOUND (our choices). WTS_ANY_SESSION -> ERROR_INVALID_PARAMETER. Unreachable server -> RPC_S_SERVER_UNAVAILABLE.
Logoff: ExitWindowsEx(EWX_LOGOFF|EWX_FORCEIFHUNG) (existing wineboot path; bWait ignored: the caller is among what ends). DEVIATION from the decision text: Disconnect locks the session (LockWorkStation, sg-lockctl) instead of ending it; Windows keeps a disconnected session and its programs, ending it would lose the user's work. Flip to ExitWindowsEx if David wants it ended.
Shutdown: needs SeShutdownPrivilege (thread token), else ERROR_PRIVILEGE_NOT_HELD; flags LOGOFF/SHUTDOWN/REBOOT/POWEROFF/FASTREBOOT mapped to ExitWindowsEx (several flags: most drastic wins); the power helper (sg-settingsctl, logind/polkit) does the rest. WTS_WSD_* added to include/wtsapi32.h.
SendMessage: box on a thread of its own (MessageBoxW + thread timer ending the dialog with IDTIMEOUT=32000, since Wine's MessageBoxTimeoutW ignores the timeout); bWait FALSE -> IDASYNC=32001 at once; lengths in bytes cut the strings; NULL response/message -> ERROR_INVALID_PARAMETER. Style passed through plus MB_SETFOREGROUND.
Unverified: exact Windows error for session 0 / unknown sessions as administrator, whether Windows' logoff is forced, FASTREBOOT meaning.
