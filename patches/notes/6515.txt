6515 wmvcore (ledger M-DSHOW: WMCreateEditor). The metadata editor.
New editor.c (from the public ASF specification): IWMMetadataEditor + IWMHeaderInfo/2/3 (QI to a writer_header store, outer = the editor). Open: header object (GUID, size <= 64 MB, count), children walked; File Properties Object required (else NS_E_INVALID_INPUT_FORMAT); CDO's five strings and ECD descriptors (types 0 string, 1 bytes, 2 BOOL(4), 3 DWORD, 4 QWORD, 5 WORD) added as stream-0 attributes; a second Open while open NS_E_INVALID_REQUEST. Flush: new header = the old children except CDO/ECD + a CDO of the five names (if any) + an ECD of the other stream-0 attributes (GUID-typed and stream-specific attributes not written: FIXME; they belong in the Metadata/Metadata Library objects); header size/count; FPO file size updated; written to <file>.sgtmp + the bytes after the old header, then MoveFileEx over the file. Close drops unflushed changes (a fresh store).
Gate wmeditor (test-wmeditor): probe writes an ASF header (FPO, CDO, ECD), a data object and payload bytes; read, change, add, delete, flush, reopen, payload and file size, Close drops, non-ASF refused. Mutants SG_MUTANT_WMED_NO_READ (12), SG_MUTANT_WMED_NO_WRITE (4) caught. wmvcore conformance 64/32: 0 failures as before.
