5209 user32: SetDisplayConfig (gap-CORE 659).
Docs: learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setdisplayconfig (flag combinations, ERROR_INVALID_PARAMETER / ERROR_BAD_CONFIGURATION / ERROR_GEN_FAILURE, SDC_ALLOW_CHANGES, SDC_SAVE_TO_DATABASE, "scenario" table).
Was: FIXME and ERROR_SUCCESS for anything. Now: unknown flag bits and every invalid combination of the docs' list give ERROR_INVALID_PARAMETER (exactly one of APPLY/VALIDATE; USE_SUPPLIED xor a TOPOLOGY flag; NO_OPTIMIZATION only with APPLY; SAVE_TO_DATABASE only with USE_SUPPLIED; PERSIST_IF_REQUIRED not with USE_SUPPLIED / TOPOLOGY_SUPPLIED; FORCE_MODE_ENUMERATION only with APPLY and USE_SUPPLIED; ALLOW_PATH_ORDER_CHANGES only with TOPOLOGY_SUPPLIED; TOPOLOGY_SUPPLIED beside another TOPOLOGY flag is ignored, as documented), arrays must be NULL/0 for the database topologies and present for the supplied ones, an active path's source mode index must be invalid or a source mode. SDC_USE_SUPPLIED_DISPLAY_CONFIG: each active path's source mode (size, position, pixel format; the path's refresh rate when given) is turned into a DEVMODE for the source's GDI device (DisplayConfigGetDeviceInfo GET_SOURCE_NAME) and tested with ChangeDisplaySettingsEx(CDS_TEST) for all sources first (all or nothing); a mode the display cannot do gives ERROR_BAD_CONFIGURATION, unless SDC_ALLOW_CHANGES, which uses the nearest enumerated mode. SDC_APPLY then changes the modes (temporary: at once; SDC_SAVE_TO_DATABASE: CDS_UPDATEREGISTRY, then one reset). Database topology requests (SDC_TOPOLOGY_INTERNAL/CLONE/EXTEND/EXTERNAL) succeed when the current topology satisfies them (extended always, internal with one display), else ERROR_BAD_CONFIGURATION; SDC_TOPOLOGY_SUPPLIED succeeds when the supplied active paths are exactly the current ones.
Unverified: there is no persistence database, so "last clone/extend configuration" is always the current one; the error for an empty/no-active-path set and for a supplied request with NULL paths (ERROR_INVALID_PARAMETER, chosen); refresh rate, target mode, scaling and rotation of the paths are not applied (only source modes); ERROR_NOT_SUPPORTED / ERROR_ACCESS_DENIED are never returned.
