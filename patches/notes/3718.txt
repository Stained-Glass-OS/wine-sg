3718 sxs (gap-CLOUD): IAssemblyName was a set of E_NOTIMPL stubs, IAssemblyCache::CreateAssemblyCacheItem too, and UninstallAssembly refused any reference. Now:
 - IAssemblyName SetProperty/GetProperty/Finalize/IsEqual/Clone. Properties (ASM_NAME_*): NAME and CULTURE are strings (size in bytes incl. NUL), MAJOR/MINOR/BUILD/REVISION are WORDs that edit the version string, PUBLIC_KEY_TOKEN is 8 bytes kept as the 16-digit hex string the cache code already uses, the other ids are stored as blobs. Size 0 removes (removing a version component drops the ones after it). A property that is not set gives S_OK with size 0; a too-small buffer gives HRESULT_FROM_WIN32(ERROR_INSUFFICIENT_BUFFER) and the size; Set after Finalize is E_UNEXPECTED (documented); ids >= ASM_NAME_MAX_PARAMS, NULL size pointer, wrong sizes: E_INVALIDARG (GUESS, undocumented). NULL_PUBLIC_KEY(_TOKEN) get: S_OK when a token is set, else S_FALSE; NULL_CUSTOM: S_OK (this is how Wine's fusion behaves; no sxs test). IsEqual compares the ASM_CMPF_* parts (name case-insensitively), a NULL other name is S_FALSE; ASM_CMPF_DEFAULT = ALL, minus the version when this name has no token (documented: "ignore the version to compare simple names"). Clone is a deep copy and not finalized (GUESS: the point of cloning is to edit the copy). GetDisplayName/GetName cope with a removed name (FUSION_E_INVALID_NAME / size 0). ASM_NAME_ARCHITECTURE is not in the sxs documentation and is not implemented.
 - CreateAssemblyCacheItem + IAssemblyCacheItem (CreateStream/Commit/AbortItem): streams live in memory; Commit lays them out in a private temp dir and runs the same install code as InstallAssembly. Partial names (no arch/token/version) are FUSION_E_INVALID_NAME (documented), a name that does not match the manifest is refused at Commit, every <file> of the manifest must have a module stream. Commit disposition: INSTALLED, REFRESHED (different content, or FORCE_REFRESH), ALREADY_INSTALLED (manifest and files identical). COMPLIB stream formats: ERROR_NOT_SUPPORTED, missing manifest/module: ERROR_FILE_NOT_FOUND, duplicate stream name: ERROR_ALREADY_EXISTS (all GUESSES). Second Commit/after Abort: E_UNEXPECTED (guess).
 - Install references: InstallAssembly(ref) records the reference (HKLM\Software\Wine\SideBySide\References\<assembly dir>, value "<scheme guid>!<id>"; the layout is ours), UninstallAssembly honours it and fills the disposition: UNINSTALLED / HAS_INSTALL_REFERENCES (refs left, or no ref given while some exist) / REFERENCE_NOT_FOUND / ALREADY_UNINSTALLED, all with S_FALSE except UNINSTALLED (the SDK lists S_FALSE as "did not succeed"). Scheme GUIDs are not checked (their values are not in the docs). Flags must be 0 for uninstall, install takes REFRESH/FORCE_REFRESH (overwrite). STILL_IN_USE is never reported (no way to know).
 - include/winsxs.idl gets ASM_CMP_FLAGS and the IASSEMBLYCACHE*/STREAM_FORMAT*/COMMIT constants (values as in Wine's fusion.idl and the SDK pages); sxs imports advapi32.
NOT done / triaged: IAssemblyCache::Reserved (scavenger) and IAssemblyName::Reserved: no SDK page lists them, no test; kept E_NOTIMPL, no-ground-truth.
