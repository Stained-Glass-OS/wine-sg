OleCreatePropertyFrameIndirect ignored OCPFIPARAMS.dispidInitialProperty (item 547,
FIXME "not yet implemented"). Implemented as the docs describe
(olectl/nf-olectl-olecreatepropertyframeindirect remarks): when it is not
DISPID_UNKNOWN, IPerPropertyBrowsing::MapPropertyToPage on the first object
names the page; that page is the sheet's start page (PROPSHEETHEADER.nStartPage),
and once activated it is asked through IPropertyPage2::EditProperty(dispid) to
highlight the property. If the object has no IPerPropertyBrowsing, the map fails,
the page is not in the list or does not implement IPropertyPage2, the frame shows
the first page as before.
Note: OleCreatePropertyFrame passed 0 for this field; docs say "when
dispIDInitialProperty is DISPID_UNKNOWN the behavior of the two functions is
identical" and 0 is DISPID_VALUE, a real property, so it now passes DISPID_UNKNOWN.
A direct OleCreatePropertyFrameIndirect caller that left the field 0 now gets a
Map(0) lookup, which is what Windows does by the docs.
