6179 dlls/icu -- XAML program, Windows Terminal. The API per ICU's public headers (utext.h, uregex.h; ICU is open source under the Unicode licence: the UText layout is taken from it, 144 bytes on 64-bit, privB and privC int32); no ICU implementation code is used: the matcher is ours.
uregex.c: UText: utext_setup (a caller's UText checked by magic, reopened: its provider's close called, extra space (re)allocated and owned; NULL: one allocated and owned), utext_close (provider close; owned extra and heap UText freed), utext_nativeLength. Access to text by native index through the provider's access callback, native index = UTF-16 offset within nativeIndexingLimit, else mapNativeIndexToUTF16.
Regex: the pattern compiled to a program (char, any, class, split, jmp, save, assert, match); classes with ranges and \d\w\s (and negations; \w: letters, marks, decimal digits, connector punctuation by u_charType); escapes \t\n\r\f\a\e\0oo\xhh\x{h}\uhhhh; assertions ^ $ (MULTILINE) \A \z \Z \b \B; groups ( ) and (?: ); | ; * + ? {m} {m,} {m,n} and lazy forms (possessive taken as greedy); intervals expanded. Not supported (U_REGEX_UNIMPLEMENTED): look-around, back references, named groups, \p classes, nested classes. A backtracking machine with an explicit stack (stack overflow and a step limit as U_REGEX_STACK_OVERFLOW / U_REGEX_TIME_OUT); case-insensitive by u_foldCase. find/findNext from the region start or the last end (an empty match advances by one).
API: uregex_open (pattern length -1: NUL-terminated; UParseError zeroed), clone (a new compilation, no text), close, setText (a UText over the caller's string), setUText (the caller's, kept), setTimeLimit/StackLimit (accepted), reset/reset64, find/find64 (-1: from the last end), findNext, matches/matches64, groupCount, start/end (+64), pattern, flags. Errors follow ICU: nothing done once *status is a failure.
