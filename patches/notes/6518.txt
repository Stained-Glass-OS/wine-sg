6518 wmvcore + winegstreamer (ledger M-DSHOW, plan step 3). The writer encodes WMA and WMV.
winegstreamer: wm_encoder.c exports winegstreamer_wm_encoder_create/get_output/push/pull/drain/destroy (AM_MEDIA_TYPE in and out; wg_transform_create_quartz -> MF types; MF samples; read retries a stream change; MF_E_TRANSFORM_NEED_MORE_INPUT -> S_FALSE; output as CoTaskMem). wg_transform.c: transform_prepare_encoder_caps (raw input, compressed output): output caps without codec_data, block_align, depth, bitrate, streamheader (and "format" for video/x-wmv), the bit rate kept (caps "bitrate", MFVIDEOFORMAT compressedInfo.AvgBitrate, or nAvgBytesPerSec*8) and set on the encoder's "bitrate" property (gint64/int/uint). Encoders: avenc_wmav2/avenc_wmav1, avenc_wmv2/avenc_wmv1 (gstreamer1.0-libav, in the image).
wmvcore writer: BeginWriting creates an encoder per input whose chosen format is not the stream's (chosen -> stream type); WriteSample pushes (MF_E_NOTACCEPTING: pull, push again) then pulls everything into the mux; output times shifted back by (first output - first input) (GStreamer video encoders add 1000 hours); samples are queued until every encoder produced output, then the encoders' actual output types (WAVEFORMATEX with codec data / VIDEOINFOHEADER with the FourCC and codec data) become the streams' formats and the header goes out with the first packet (asf_mux_begin now only opens; start_header at the first write or at the end); EndWriting drains, flushes the queue, ends the file. Inputs that neither are the stream format nor have an encoder: NS_E_INVALID_INPUT_FORMAT.
asfmux.c: header extension carries an Extended Stream Properties Object per stream (bit rates, buffer size from the buffer window, max object size at the end, seekable, average time per frame for video). Simple index fix (of 6517): entries count in presentation time (entry i = time i s - preroll), the count includes the preroll — Wine's reader (asfdemux) started 1.2 s into a file otherwise.
