GetBlockMap (package and bundle readers), IAppxFactory::CreateBlockMapReader/CreateValidatedBlockMapReader and IAppxManifestReader::GetDeviceCapabilities were FIXME E_NOTIMPL; the block map interfaces were only forward-declared.
IDL (appxpackaging.idl): IAppxBlockMapBlock (75cf3930-3244-4fe0-a8c8-e0bcb270b889), IAppxBlockMapBlocksEnumerator (6b429b5b-...), IAppxBlockMapFile (277672ac-...), IAppxBlockMapFilesEnumerator (02b856a2-...), IAppxBlockMapReader (5efec991-...), IAppxManifestDeviceCapabilitiesEnumerator (30204541-...); layouts and IIDs from the MIT windows-rs 0.58 Win32 metadata.
New blockmap.c:
- parses AppxBlockMap.xml (SHA-256/384/512 hash methods; File Name/Size/LfhSize; Block Hash and optional Size -- a stored block's compressed size is its length); duplicates, wrong block counts and bad hashes are APPX_E_INVALID_BLOCKMAP.
- IAppxBlockMapReader: GetFile (case-insensitive; unknown: HRESULT_FROM_WIN32(ERROR_FILE_NOT_FOUND)), GetFiles, GetHashMethod (IUri through CreateUri), GetStream (a copy of the XML).
- IAppxBlockMapFile: GetBlocks, GetLocalFileHeaderSize, GetName (CoTaskMem), GetUncompressedSize, ValidateFileHash (the stream from its start: every block's hash and exactly the file's size).
- IAppxBlockMapBlock: GetHash (the block's own buffer, valid while the block is), GetCompressedSize.
- CreateValidatedBlockMapReader: the signature file must start with "PKCX"; its PKCS #7 message must verify with its signer certificate (CryptMsgControl CMSG_CTRL_VERIFY_SIGNATURE; the chain is not checked here, WinVerifyTrust does that for packages), and the AXBM digest in its content must be the SHA-256 of the block map (TRUST_E_BAD_DIGEST otherwise; TRUST_E_NOSIGNATURE for a file that is not a signature).
package.c: GetBlockMap of a package (and a bundle) reads its AppxBlockMap.xml into a block map reader.
manifest.c: DeviceCapability elements under Capabilities are kept (names, in order) and enumerated by GetDeviceCapabilities (CoTaskMem strings).
test/mkappx.py: the fixture manifest has two DeviceCapability elements (webcam, microphone).
