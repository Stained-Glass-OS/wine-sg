dbgeng: ~230 methods of the engine (clients, control, symbols, advanced, system objects) done on top of fast-a 3008 (the patch needs 3008 applied first).
DEPENDS ON fast-a 3008; merge fast-a first.
Live targets (create/attach, WaitForEvent events and filters, software breakpoints, stepping), dbghelp-backed symbols/types/scope/symbol groups, expression evaluator and command interpreter, capstone disassembly, log files, filters, aliases, wide variants.
Gate fastb-dbgeng-gate.sh (157 checks per architecture, 64 and 32 bit, builds its probe with the tree's winegcc); conformance dbgeng 94 tests 0 failures 64+32.
Not done: kernel debugging, process servers/remote, OpenDumpFile/AddDumpInformationFile (dump targets), CreateClient, Assemble, ReadBugCheckData, GetWindbgExtensionApis, SetScopeFromJitDebugInfo, RemoveSyntheticSymbol (dbghelp SymDeleteSymbol is a stub).
Unverified against Windows: default exception filter list, SetSystemErrorControl defaults, event index calls (E_NOINTERFACE), dt/r/lm/k output layout, Request/GetSymbolInformation sub-requests beyond the ones listed.
