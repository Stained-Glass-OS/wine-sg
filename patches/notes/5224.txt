5224 gdi32 (uniscribe): OpenType contextual lookups, alternate glyphs and feature filtering (gap-CORE 237, 238, 239, 240, 838).
Docs: the OpenType specification (learn.microsoft.com/en-us/typography/opentype/spec/gsub and /gpos: ChainContextSubstFormat1, ContextPosFormat1/3, ChainContextPosFormat1/2, AlternateSubstFormat1, ExtensionSubst), learn.microsoft.com/en-us/windows/win32/api/usp10/nf-usp10-scriptgetfontalternateglyphs and nf-usp10-scriptgetfontfeaturetags.
237 GSUB ChainContextSubst format 1 (glyph-sequence rules: backtrack, input, lookahead, lookup records) was skipped with a FIXME; 238 GPOS ContextPos format 1 and 3 and 239 GPOS ChainContextPos format 1 and 2 likewise; they now match and apply their lookup records the way the format 2/3 code beside them does (backtrack read backwards from the glyph, the position functions return the number of glyphs consumed, the input glyph count).
838 ScriptGetFontAlternateGlyphs returned E_NOTIMPL: it now lists the glyph itself followed by the alternates of the feature's alternate-substitution lookups (also through extension lookups); E_OUTOFMEMORY with the count when the list is too short, E_INVALIDARG without list/count/size, USP_E_SCRIPT_NOT_IN_FONT for a script the font lacks, S_OK with count 0 when the feature or the glyph has no alternates; tagLangSys 0 means the default language.
240 ScriptGetFontFeatureTags with an analysis hid nothing ("Filtering not implemented"): it now leaves out the features the script's shaping engine requires (Wine's per-script required-feature lists, e.g. fina/init/medi/rlig for Arabic), as the docs say ("hides script-required or language-required features").
Unverified: what native returns for a glyph without alternates (count 0 here, native may give just the glyph); the language-required feature of a LangSys is not hidden (only the engine's list); GSUB ContextSubst format 3 and ChainContextSubst format 2/3 were already there, ContextSubst format 3 is still missing (not in this item).
Gate test/gdi32-opentype-gate.sh (64/32 bit) builds a font with GSUB/GPOS tables written from the specification (test/sgfont.h now takes an optional GPOS) and checks shaping, advances, alternates and tag lists; mutants OT_CHAIN1, OT_CTXPOS1, OT_CTXPOS3, OT_CHAINPOS1, OT_CHAINPOS2, OT_ALT and SHAPE_NOFILTER shown failing it.
