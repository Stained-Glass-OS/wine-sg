3303 shell32 (CORE review). ExtractAssociatedIconExW: GUESSES: the id of an icon group named by a string is 0; the id is only set when an icon is found and the path is a module with icon groups; a file whose type has an association but for which ExtractIconW returns NULL (not 1) still takes the generic icon (existing ExtractAssociatedIconW behaviour, not changed; negative indices are not supported by it either).
Desktop SetNameOf: only the user's desktop directory (the folder enumerates only that); renaming namespace items (My Computer, Recycle Bin) is not implemented (returns E_FAIL; Windows keeps the name in HKCU); the returned pidl is the simple item of the new file.
