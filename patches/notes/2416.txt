2416 iphlpapi: network writes through sg-netctl (coordinator decision 8). New netwrite.c; Create/Delete/SetUnicastIpAddressEntry, Create/Delete/SetIpForwardEntry2, Create/Delete/SetIpNetEntry2, FlushIpNetTable2, FlushIpPathTable, Create/DeleteAnycastIpAddressEntry exported (prototypes added to include/netioapi.h); legacy AddIPAddress/DeleteIPAddress/Create|Delete|SetIpForwardEntry/Create|Delete|SetIpNetEntry/FlushIpNetTable now act too.
Rights: Administrators group in the caller's token (thread token honoured) else ERROR_ACCESS_DENIED, checked after argument validation and before sg-netctl is asked. sg-netctl itself also decides from the Unix account.
sg-netctl has these commands since sg-session 6fff479 (0.1.0-185), plus the reply kind exists (-> ERROR_OBJECT_ALREADY_EXISTS). Requests used (stand-in in the gate): addr add|del DEVICE ADDR/PREFIX; route add|del|set DEVICE DEST/PREFIX [--gateway A] [--metric N]; neigh add DEVICE ADDR HWADDR [--permanent]; neigh del DEVICE ADDR; neigh flush [DEVICE] [--family 4|6]. Replies as the other commands (OK / ERROR kind msg). Every call returns the real result. Only with no sg-netctl at all (plain Wine): new calls give ERROR_NOT_SUPPORTED, the legacy calls keep the old quiet NO_ERROR with a FIXME (coordinator).
Choices: default prefix (OnLinkPrefixLength 255) = address class for IPv4, 64 for IPv6; SetUnicastIpAddressEntry only checks the address exists (lifetimes are the system's); anycast = ERROR_NOT_SUPPORTED after the admin check; FlushIpPathTable = NO_ERROR (no path cache); AddIPAddress contexts are per-process (a table in the DLL); unknown context to DeleteIPAddress = ERROR_INVALID_PARAMETER; interface name = the interface row's Alias (the Linux name).
Not done: CreateProxyArpEntry/DeleteProxyArpEntry, persistent port reservations, EnableRouter (later, as the coordinator said).
Gate: test/netwrite-gate.sh (64+32; stand-in sg-netctl script via SG_NETCTL; 10 rows incl. non-admin via restricted impersonation token, every refusal kind, no sg-netctl). Mutants caught: SG_MUTANT_NW_{NOADMIN,PREFIX,GATEWAY,LEGACY}.
Conformance: iphlpapi tests 740, 0 failures. No todo_wine in them covers these calls.
