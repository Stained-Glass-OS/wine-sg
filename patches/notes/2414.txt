2414 powrprof: SetSuspendState through systemd-logind (coordinator decision 7). New Unix library powrprof.so (dlopens libdbus like mountmgr; DBUS_SYSTEM_BUS_ADDRESS honoured by libdbus, which the gate uses).
Flow: SeShutdownPrivilege (thread token, else ERROR_PRIVILEGE_NOT_HELD); CanSuspend/CanHibernate ("na" -> FALSE ERROR_NOT_SUPPORTED, "no" -> ERROR_ACCESS_DENIED); Suspend/Hibernate(interactive=false); AccessDenied / InteractiveAuthorizationRequired -> ERROR_ACCESS_DENIED, other errors ERROR_GEN_FAILURE; then wait for PrepareForSleep(true) (5 s) and PrepareForSleep(false) (no limit) so TRUE means "back from sleep". No libdbus / no system bus -> ERROR_NOT_SUPPORTED.
Unverified: Windows error codes for refusal (ERROR_ACCESS_DENIED / ERROR_NOT_SUPPORTED / ERROR_GEN_FAILURE are our picks; privilege is the documented requirement); ForceCritical and DisableWakeEvent are ignored (logind has no equivalent).
Gate: test/suspend-gate.sh (64+32): stand-in logind in C (test/suspend-logind-standin.c) on a private dbus-daemon, 9 table rows (suspend, hibernate, na, no, challenge+denied, failure, no bus, no privilege). Needs dbus-daemon, libdbus headers, gcc (SKIPs otherwise). Mutants caught: SG_MUTANT_SUSPEND_ALWAYS_TRUE (powrprof.c), SG_MUTANT_SUSPEND_NOWAIT, SG_MUTANT_SUSPEND_HIBSWAP (unixlib.c).
Build note: Makefile.in gains UNIXLIB, so configure/make must regenerate the Makefile (a normal make does).
