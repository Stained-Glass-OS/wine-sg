New writer.c:
- the output stream is written from its current position, file by file: local header (UTF-8 flag, CRC-32, sizes; ZIP64 extra field when a size does not fit 32 bits), name, data. Inputs are read whole (up to 2 GiB each).
- compression: NONE stored; NORMAL deflate level default, MAXIMUM 9, FAST/SUPERFAST 1; raw deflate with Z_FULL_FLUSH after every 64 KiB of input and Z_FINISH on the last block, so every block's compressed size is known.
- names: '\\' to '/', OPC percent-encoding of what is not unreserved/sub-delim/':'/'@' (a space is %20); [Content_Types].xml stored literally. Empty, absolute, '/'-containing, footprint (AppxManifest.xml, AppxBlockMap.xml, AppxSignature.p7x, [Content_Types].xml, AppxMetadata files) and repeated (case-insensitive) names: E_INVALIDARG. After Close (or a failed write): E_UNEXPECTED.
- content types: one Default per extension, an Override for a part whose type differs from its extension's or that has none; plus the manifest and block map types.
- Close: the manifest must be one manifest_reader_create takes (APPX_E_INVALID_MANIFEST otherwise); then AppxManifest.xml (deflated), AppxBlockMap.xml (HashMethod, File Name/Size/LfhSize, Block Hash and, for deflated files, Size), [Content_Types].xml, the central directory and its end record (ZIP64 end records when needed; with forceZip32 those are APPX_E_REQUESTED_RANGE_TOO_LARGE).
- settings.hashMethod: SHA-256 (default), SHA-384 or SHA-512; others E_INVALIDARG.
