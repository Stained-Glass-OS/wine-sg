Section 4 / DECISIONS-2 N-MISC: sensapi!IsDestinationReachableA/W, connect!IsInternetConnected. Reachable = the name resolves (GetAddrInfoW) and GetBestInterfaceEx finds an interface; QOC flags NETWORK_ALIVE_LAN and the interface speed (GUESS: Windows measures the connection; WAN vs LAN is not distinguished). IsInternetConnected: a route to 8.8.8.8 (a default route) -> S_OK else S_FALSE. IsNetworkAlive is unchanged (still always alive). Gate fastb-sens: results are checked against the routing table of the machine; mutants SENS_ALWAYS, SENS_NOARGS, SENS_NOQOC caught; CON_ALWAYS (IsInternetConnected always S_OK) is NOT caught on a machine that has a default route (the gate can not remove the route) and would be caught on one without.
