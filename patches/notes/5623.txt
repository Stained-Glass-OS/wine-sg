New condrv ioctls 70-73 (IOCTL_CONDRV_ADD_ALIAS / GET_ALIAS / GET_ALIASES / GET_ALIAS_EXES, include/wine/condrv.h); conhost keeps, per console, a list of executables each with a list of (source, target) aliases, matched without regard to case; kernelbase console.c wraps them. AddConsoleAlias with an empty or NULL target removes the alias (the last alias of an executable removes the executable). GetConsoleAlias: bytes copied including the NUL, ERROR_INSUFFICIENT_BUFFER when it does not fit, ERROR_NOT_FOUND when absent, ERROR_INVALID_PARAMETER for an empty source or executable. GetConsoleAliases / GetConsoleAliasExes: "source=target" strings each ended by a NUL, the executables each ended by a NUL, sizes in bytes (A forms: bytes in the console code page). The status travels in the ioctl payload because console_ioctl flattens failures. New exports GetConsoleAliasesA/W and GetConsoleAliasExesA/W in kernelbase.spec and kernel32.spec. Docs: AddConsoleAlias, GetConsoleAlias, GetConsoleAliases, GetConsoleAliasesLength, GetConsoleAliasExes, GetConsoleAliasExesLength.
