Proposal: SG has one interactive session (+ services session 0): LogonId/TargetLogonId not in WTSEnumerateSessions list -> ERROR_CTX_WINSTATION_NOT_FOUND (winerror.h:2152); TargetLogonId = services session -> ERROR_ACCESS_DENIED; connecting to the current session to itself -> fail (nothing to reconnect) rather than TRUE; password checked via LogonUser path when switching users. A converts to W.
- WTSConnectSessionW (fixme-stub, dlls/wtsapi32/wtsapi32.c:329): Sessions. W form of 785: same proposal; never report success for a connection that did not happen.
- WTSStartRemoteControlSessionA (fixme-stub, dlls/wtsapi32/wtsapi32.c:1904): Sessions (remote control/shadow). Returns FALSE without SetLastError. Proposal: no RDS shadowing stack: validate target session id (ERROR_CTX_WINSTATION_NOT_FOUND) and server (non-local -> RPC_S_SERVER_UNAVAILABLE as other SG WTS calls), else SetLastError(ERROR_NOT_SUPPORTED); A converts to W.
- WTSStartRemoteControlSessionW (fixme-stub, dlls/wtsapi32/wtsapi32.c:1913): Sessions (shadow). Same as 787 for W.
- WTSStopRemoteControlSession (fixme-stub, dlls/wtsapi32/wtsapi32.c:1922): Sessions (shadow). WTSStopRemoteControlSession: no shadow can be active -> FALSE with ERROR_CTX_WINSTATION_NOT_FOUND for unknown ids / ERROR_NOT_SUPPORTED otherwise (currently no last error).
- WTSVirtualChannelClose (fixme-stub, dlls/wtsapi32/wtsapi32.c:2009): RDP virtual channels (b). No RDP stack; Open never returns a handle, so Close can only see invalid handles: SetLastError(ERROR_INVALID_HANDLE), FALSE. Real channels need an RDP server design.

- WTSWaitSystemEvent (fixme-stub, dlls/wtsapi32/wtsapi32.c:2082): Sessions. Returns FALSE with no error. learn .../nf-wtsapi32-wtswaitsystemevent: waits for WTS_EVENT_* (LOGON, LOGOFF, STATECHANGE, CONNECT/DISCONNECT...), WTS_EVENT_FLUSH makes pending waits return with WTS_EVENT_NONE. Proposal: hook into SG's compositor session notifications (wtsapi32.c:37): block until a masked event (lock/unlock -> STATECHANGE, logoff -> LOGOFF), return flags; FLUSH wakes waiters; non-local server -> RPC_S_SERVER_UNAVAILABLE.
- WTSEnumerateProcessesExW (notimpl, dlls/wtsapi32/wtsapi32.c:535): Sessions. WTSEnumerateProcessesExW ignores session_id (returns all processes). Tests wtsapi.c:185-188 only cover WTS_ANY_SESSION. Proposal: when session_id != WTS_ANY_SESSION, include only SYSTEM_PROCESS_INFORMATION entries whose SessionId == session_id (unknown session -> empty list/ERROR_SUCCESS as Windows enumerates); non-admin callers see other sessions' processes only as Windows does (needs admin for session 0 detail).
